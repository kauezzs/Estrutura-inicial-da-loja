# ROUGH — Loja Virtual de Streetwear

E-commerce fictício (skates, roupas, tênis e acessórios) feito com **HTML, CSS e JavaScript puro** para a disciplina de Criação de Sites.

## Funcionalidades
- Home, categorias, listagem com busca e filtros (categoria/preço)
- Página de detalhes do produto
- Carrinho funcional (adicionar, alterar quantidade, remover, total) salvo no `localStorage`
- Cupom de desconto: `ROUGH10` (10%)
- Checkout com dados do cliente e pagamento simulado: crédito (com parcelamento até 6x), débito e PIX
- Tela de compra realizada, histórico de pedidos no `localStorage`
- Responsivo (computador e celular)

## Como executar
Abra o arquivo `index.html` no navegador (nenhuma instalação necessária).
Para usar fotos reais, coloque os arquivos na pasta `img/` com os nomes definidos em `js/app.js`.
